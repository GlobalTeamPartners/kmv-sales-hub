# Глобал Плюс × Global Team Partners | Центр Продаж: Кавказские Минеральные Воды (КМВ)

Интегрированная система региональной экспансии, коммерческих предложений, базы целевых предприятий и готовых цифровых B2B-систем для региона **Кавказских Минеральных Вод (КМВ)**.

Проект разработан по архитектуре и высоким стандартам [Ural Sales Kit](https://globalteampartners.github.io/ural-sales-kit/) и кастомизирован под экономику, менталитет и деловую специфику ключевых курортных и промышленных центров Ставропольского края:
**Пятигорск • Кисловодск • Ессентуки • Железноводск • Минеральные Воды • Лермонтов • Георгиевск**.

---

## 📊 Ключевые Метрики Комплекта

* **72 целевых предприятия** в едином реестре с выявленными болями, ЛПР, контактами и точечными офферами.
* **16 специализированных отраслевых решений Global Plus** (Санатории 4-5*, Розлив минеральных вод, Легпром, Меховой кластер, Курортный девелопмент, Медицинские клиники, Эстетическая стоматология, Машиностроение, Агрохимия, Пищепром, HoReCa, Авиахаб, Горный туризм, Детейлинг).
* **7 городов агломерации КМВ** с детальной географической и отраслевой сегментацией.
* **48 часов** — гарантированный срок развертывания боевого прототипа под клиента.

## 🚀 Инструкция по Развертыванию на GitHub Pages

Комплект полностью автономен и не требует сборщиков или бэкенда. Чтобы опубликовать его в интернет:

1. Создайте репозиторий на GitHub (`kmv-sales-hub` в аккаунте `GlobalTeamPartners`):
   ```bash
   git init
   git add .
   git commit -m "Initial commit: KMV Sales Hub (72 enterprises, 16 solutions, competitor intelligence)"
   git branch -M main
   git remote add origin https://github.com/GlobalTeamPartners/kmv-sales-hub.git
   git push -u origin main
   ```
2. Перейдите в **Settings -> Pages** в настройках репозитория.
3. В графе **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
4. Сайт доступен по адресу:
   `https://globalteampartners.github.io/kmv-sales-hub/`

## 💼 Инструкция для Регионального Партнера на Встречах

1. **Перед встречей:**
   * Откройте `Leads_List.html`, найдите компанию, изучите выявленную боль и предложенный оффер.
   * Откройте `Dynamic_Pitch_Deck.html?id=ID_КОМПАНИИ` на iPad.
   * Распечатайте на листе А4 документ из `Dynamic_One_Pager.html?id=ID_КОМПАНИИ`.
2. **На встрече:**
   * Следуйте плейбуку из `Solo_Executive_Strategy.html`.
   * Покажите 4 слайда на планшете за 2 минуты.
   * Откройте живой демо-сайт из каталога, покажите скорость и визуал.
   * Передайте распечатанный 1-Pager руководителю со словами: *«Мы берем техническую часть на себя, запуск за 48 часов, окупаемость в первый месяц»*.
